বাজার দর (BazarDor)

Today's Market Prices at a Glance

বাজার দর (BazarDor) is a responsive web application that helps users easily check the latest prices of essential daily products in Bangladesh. Users can explore different product categories, compare prices, and view detailed product information in one place.

🚀 Technologies Used

Next.js – React framework for building the application

React.js – Building reusable UI components

Tailwind CSS – Responsive styling and modern UI design

JavaScript – Application logic and functionality

REST API – Fetching product and category data

React Toast – Displaying notifications

Vercel – Deployment and hosting

✨ Key Features

Today's Market Prices: View the latest prices of essential daily products in Bangladesh.

Product Categories: Browse products by categories such as Rice, Dal, Oil, Vegetables, Fish, Meat, and more.

Product Details: View detailed information about individual products, including current and previous prices.

Price Comparison: Explore price changes to identify which products have increased or decreased in price.

Authentication & Responsive Design: User authentication with a responsive interface for mobile, tablet, and desktop devices.
